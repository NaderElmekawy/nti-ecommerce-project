# NTI E-Commerce Project 

A responsive e-commerce web application developed as part of the **NTI (National Telecommunication Institute) training program**.

The project allows users to browse shoes, filter products, view product details, select different colors and sizes, and manage their shopping cart.

---

## 🚀 Features

- **Product Catalog:** Browse a collection of shoes with category filtering.
- **Search:** Search for products by name.
- **Product Details:** View product images, pricing, ratings, colors, sizes, and descriptions.
- **Color Selection:** Change the displayed product image when selecting a different color.
- **Category Filtering:** Filter products by categories such as Running, Sneakers, Basketball, Casual, Boots, and Sandals.
- **New Arrivals & On Sale:** Browse newly added and discounted products.
- **Shopping Cart:** Add products to the cart and manage quantities.
- **Cart Counter:** Displays the current number of items in the cart.
- **Notifications:** Shows a notification when a product is added to the cart.
- **Dark/Light Mode:** Switch between dark and light themes with the selected theme saved across pages.
- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.
